# Personal Research and Useful Learning Resources for esp32-Keriics
This is a directory to centralize all of my OS learning resources in this repo so that when I'm switching between systems I'm not constantly tracking down my documentation and redownloading it in a needless cycle. I simply need clone this one repo and everything I need is there.

This will be marked up with all of my notes and findings, as well as mini-projects I use to learn about systems. If you want the original repos they're listed as submodules.

## Personal Research Methodology
My goal with this is to follow a pattern of
1. Define a problem to solve and make an intial attempt to solve it using what I already know.
2. Fail.
3. List questions whose answers are needed to understand **why** I failed.
4. Research for the answers to these questions.
5. Use what I learnt to create a new iteration.
6. GOTO step 2.
